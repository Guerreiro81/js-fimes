
# 🎬 Cine Pipoca

Projeto desenvolvido para praticar HTML, CSS e JavaScript, permitindo organizar filmes e séries favoritos em uma única página.

## 🚀 Funcionalidades

- 🎬 Cadastro de filmes
- 📺 Cadastro de séries
- 🗑️ Exclusão de filmes e séries
- 🔢 Contador de itens cadastrados
- 🔎 Busca de filmes utilizando uma API
- 🌙 Alternância entre modo claro e escuro
- 💾 Armazenamento local com localStorage

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- API The Movie Database (TMDB)
- LocalStorage

## 📂 Estrutura do projeto

```text
js-filmes/
├── README.md
└── desafio-js/
    └── js/
        ├── index.html
        ├── script.js
        └── css/
            └── style.css
```

## ▶️ Como executar

1. Clone ou baixe este repositório.
2. Abra a pasta do projeto no VS Code.
3. Abra o arquivo `desafio-js/js/index.html` no navegador.
4. Utilize os formulários para cadastrar seus filmes e séries.
